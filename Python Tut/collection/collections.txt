Counter

It saves count of elements as a dictionary

1. you can use it to count the number of elements in a list or string, use .keys to get the unique elements and .values to get the count of each element
and .values to get the count of each element
from collections import Counter

a = "baaaabbbc"
my_counter = Counter(a)
print(my_counter.keys())

2. you can use .most_common to get the most common elements and their counts
print(my_counter.most_common(1)[0][1])

3. you can use .elements to get a list of elements with their counts (.elements return an iterator we typcase into a list)
print(list(my_counter.elements()))

Named Tuple

1. Named tuple is a subclass of tuple that allows you to access elements by name instead of index(kind of a class with getters ans setters)
Point = namedtuple("Point", "x,y")
pt = Point(1, -4)
print(pt.x, pt.y)

Default Dict

1. Default dict is a subclass of dict that allows you to specify a default value for missing keys(you always have to define a data type)
d = defaultdict(int)
d["a"] = 1
d["b"] = 2

print(d["c"])

Deque

1. Deque is a double-ended queue that allows you to add and remove elements from both ends
d = deque()
d.append(1)
d.append(2)
d.appendleft(3)

print(d.popleft())

# d.clear()
d.extendleft([1, 2, 3])
print(d)

# one place to the right
d.rotate(1)
print(len(d))
print(d[len(d) - 1])
